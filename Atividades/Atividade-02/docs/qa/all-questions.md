## Dicas

- Leia cada resposta antes da apresentação.
- Pratique falando sobre o propósito do projeto.
- Lembre-se de mencionar acessibilidade e responsividade.
- Use os documentos separados para se preparar por área.
- Traga exemplos do código ao explicar cada parte.
