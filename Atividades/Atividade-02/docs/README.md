# Visão geral do projeto — Portfólio da Dupla

## Sobre o projeto

Este trabalho é um portfólio acadêmico desenvolvido por Jefferson Coqueijo Fidelis e Hugo Henrrique de Vieira Almeida para a disciplina de Aplicações para Internet.

O site foi feito para:

- apresentar o currículo e projetos da dupla
- mostrar experiência em desenvolvimento web
- demonstrar boa organização visual e funcional
- facilitar a leitura e a navegação do professor
- servir como material de apresentação na aula

## Para que serve

Este portfólio funciona como uma página de apresentação profissional e acadêmica.

Ele apresenta:

- quem são os autores
- suas experiências e habilidades
- projetos em destaque
- formas de contato

Além disso, o site mostra que a dupla sabe construir uma página moderna, acessível e responsiva.

## Intenção

A intenção principal é impressionar o professor com:

- conteúdo claro e organizado
- navegação simples entre seções
- uso de recursos modernos de front-end
- um visual consistente e atraente

## O que o usuário encontra aqui

- uma capa inicial com o nome e propósito do portfólio
- biografias e habilidades de cada autor
- experiências profissionais ou acadêmicas
- projetos com descrições e links
- contato com e-mail, GitHub e LinkedIn
- formulário para enviar mensagem
